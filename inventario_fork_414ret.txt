================================================================================
¿QUÉ ES MOOSE?
================================================================================
Mission Object Oriented Scripting Environment: framework Lua grande y de terceros
para DCS World. Pone clases de alto nivel (spawns, despachadores de IA A2A, ATC,
detección, rangos...) sobre la API cruda de DCS. Si una feature es "MOOSE-dep":
el .miz carga toda la librería MOOSE (varios MB) en el sim, la lógica corre DENTRO
de DCS en tiempo real (no se unit-testea en Python, se prueba volando), queda atada
